# Lapochka Discord Music Bot

## Описание
Бот для проигрывания музыки в Discord с поддержкой Wavelink, очереди, кнопок управления и красивых embed-ов.

## Быстрый старт
1. Склонируйте репозиторий
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Скопируйте .env.example в .env и заполните переменные:
   ```
   cp .env.example .env
   ```
4. Запустите бота:
   ```
   python bot.py
   ```

## Переменные окружения
- `DISCORD_TOKEN` — токен вашего Discord-бота
- `LAVALINK_HOST`, ... — адреса и пароли ваших Lavalink серверов
- `LAVALINK_NODE_INDEX` — индекс используемого сервера (0-3)

## Особенности
- Поддержка очереди треков
- Кнопки управления (play/pause, stop, skip, queue)
- Красивые embed-ы с карточками треков
- Логирование событий

## Требования
- Python 3.10+
- Запущенный Lavalink сервер
