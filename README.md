# Lapochka Discord Music Bot

## Описание
Многофункциональный Discord-бот для музыки, поздравлений, приветствий и администрирования. Современная архитектура на базе Cog-классов, централизованных сообщений и красивых embed-ов.

## Архитектура
- **Cog-классы**: Все команды и события реализованы как отдельные Cog-и (`commands/`, `events/`).
- **Централизованные сообщения**: Все тексты ошибок, подсказок и успехов вынесены в `utils/messages.py`.
- **Embed-ы**: Для всех embed-сообщений используются функции из папки `embeds/`.
- **Права**: Проверки прав централизованы через декораторы (`utils/decorators.py`).
- **Конфиги и база**: Настройки и данные хранятся в `settings.json` и SQLite (`database/`).
- **Логирование**: Вся активность логируется в `logs/`.

## Быстрый старт
1. Склонируйте репозиторий
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните переменные:
   ```
   cp .env.example .env
   ```
4. Запустите Lavalink сервер (требуется Java 17+):
   ```
   java -jar lavalink/Lavalink.jar --spring.config.location=lavalink/application.yml
   ```
5. Запустите бота:
   ```
   python bot.py
   ```

## Переменные окружения
- `DISCORD_TOKEN` — токен вашего Discord-бота
- `LAVALINK_HOST`, `LAVALINK_PASSWORD` — адрес и пароль вашего Lavalink сервера
- `LAVALINK_NODE_INDEX` — индекс используемого сервера (0-3)

## Особенности
- Поддержка очереди треков и управления музыкой через кнопки
- Приветствия новых участников с embed-ами и меню
- Поздравления с днями рождения
- Гибкая настройка через команды `/setup`
- Централизованная работа с embed-ами и текстами
- Логирование событий

## Best practices и обновления
- Весь код структурирован по Cog-классам
- Все сообщения и embed-ы централизованы
- Проверки прав через декораторы
- Документация и docstring-и для всех основных классов и функций
- Неиспользуемый код удалён, импорты приведены к единому стилю

## Требования
- Python 3.10+
- Java 17+ (для Lavalink)
- Запущенный Lavalink сервер
